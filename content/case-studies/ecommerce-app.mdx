## Solution

- Browsing app against a live REST API with infinite scroll pagination, debounced search and category filtering.
- Persistent shopping cart using SharedPreferences with an AsyncNotifierProvider.
- Bottom navigation using go_router's StatefulShellRoute with preserved tab state.
- Repository Pattern and Dependency Inversion keep the domain layer isolated from Dio and JSON parsing details.
