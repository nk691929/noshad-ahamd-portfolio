## Solution

- Offline-first, collaborative inventory app built with Flutter and Clean Architecture, with local persistence in Hive.
- Role-based access control enforced at both the UI and the use-case layer, verified by tests that call the use case directly, independent of any UI.
- An offline sync queue with Hive persistence and a sealed-class operation hierarchy using a discriminator pattern, supporting bounded retries and Last-Writer-Wins conflict resolution.
- Optimistic stock updates with automatic rollback on permanent failure.
- CI with GitHub Actions running static analysis and the unit and widget test suite on every pull request.
