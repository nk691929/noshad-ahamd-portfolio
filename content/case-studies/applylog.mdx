## Solution

- Job application tracking with Firebase Authentication and Firestore.
- A StreamProvider-based auth state with go_router redirect logic for automatic route protection.
- Local notifications with flutter_local_notifications, scheduled through a dedicated ScheduleFollowUpReminder use case.
- A deterministic polynomial hash converts Firestore document IDs into valid Android notification IDs.
