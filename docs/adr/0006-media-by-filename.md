# ADR 0006: Project media discovered by filename convention

- Status: accepted
- Context: the owner must add photos and preview videos without touching components or content files, and the site must look right when files are missing.
- Decision: `lib/media.ts` looks for `public/media/<slug>.*` and `public/images/profile.*` on the server at build/revalidate time. Cards without media render without a media block. Videos are loaded lazily, muted, looped, paused off-screen, not autoplayed under reduced motion, and carry a pause/play control. Website previews are generated by `scripts/capture-previews.mjs` (Playwright).
- Alternatives: media paths in content (extra edits, easy to break links); external video hosting (cost, third-party scripts, CSP).
- Consequences: filenames are the contract (documented in docs/MEDIA_GUIDE.md); large files must be kept small.
